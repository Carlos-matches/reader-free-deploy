# 各平台免费方案对比（已逐个核实官方文档）

> 核实时间：2026-10 · 所有结论均来自各平台**官方定价/文档页面**，非二手转述。
> 平台政策会变，部署前建议再确认一次。

## 核心结论

**没有**「无需信用卡 + 永久免费 + 能跑 Docker + 有持久磁盘」的方案。

原因：reader 必须有 **常驻进程** + **可写持久磁盘**（SQLite 数据库）。
免费 PaaS 的商业模式恰好相反——它们要么按用量收费，要么用临时文件系统来防止资源滥用。

**真正免费的方案 = 用 IaaS 的永久免费额度自建**（Google Cloud / Oracle），代价是注册时要绑卡验证（不扣费）。

## 为什么 Netlify 不行（技术细节）

reader 需要满足以下条件，而 Netlify 全部不满足：

| 需求 | reader | Netlify |
|---|---|---|
| 常驻进程 | Node.js/Fastify 服务器持续运行 | 仅静态文件 + 无状态函数 |
| 持久磁盘 | SQLite 存 `/data`（账号/书架/进度） | 临时文件系统，随时清空 |
| 执行时长 | 扫描书库、下载整本书（分钟级） | 函数超时 10～26 秒 |
| 端口监听 | 监听 `$PORT` | 不支持长连接服务器 |

即使强行打包成函数，也会因为「**每次请求数据全部丢失**」而完全不可用。
