## 部署步骤（图文）

### ① 注册 Google Cloud

打开 👉 <https://cloud.google.com/> ，点右上角 **「开始使用」**。

> ⚠️ **必须绑定信用卡或借记卡**用于身份验证。
> Google 会做约 $1 的预授权然后**自动退还**，不会实际扣费。
> 本方案所有资源都在永久免费额度内。

注册后你会获得 **$300 试用金**（90 天）。试用金过期后，**Always Free 额度依然永久免费**。

### ② 创建项目

1. 进入 <https://console.cloud.google.com/>
2. 顶部项目选择器 → **新建项目**
3. 名字随便填，例如 `my-reader`
4. 记下**项目 ID**（形如 `my-reader-123456`）

### ③ 安装 gcloud 命令行工具

| 系统 | 命令 / 链接 |
|---|---|
| **Windows** | <https://cloud.google.com/sdk/docs/install#windows> |
| **macOS** | `brew install --cask google-cloud-sdk` |
| **Linux** | `curl https://sdk.cloud.google.com \| bash && exec -l $SHELL` |

### ④ 登录并选择项目

```bash
gcloud auth login
gcloud config set project 你的项目ID
```

### ⑤ 运行一键部署

```bash
# 克隆本仓库
git clone https://github.com/你的用户名/reader-free-deploy.git
cd reader-free-deploy/scripts

# 一键部署！（约 2-3 分钟）
bash deploy-gcp.sh
```

**脚本会自动完成：**
- ✅ 启用 API、预留固定 IP
- ✅ 配置防火墙、创建 30GB 数据盘
- ✅ 创建虚拟机、安装 Docker
- ✅ 启动 reader 并设置开机自启

### ⑥ 开始使用

等 **1～2 分钟**后，打开终端显示的地址：

```
http://你的公网IP/
```

🎉 **第一个注册的账号自动成为管理员！**

## 部署后第一件事

### 1️⃣ 导入书源（能搜书的关键）

登录后 → 左侧 **书源管理** → **导入书源** → 选**网络导入**，粘贴：

```
https://raw.githubusercontent.com/shidahuilang/shuyuan/shuyuan/book.json
```

导入后回到**发现**页即可搜索全网小说。

> 💡 书源失效很正常，建议多导入几份备用。在 GitHub 搜 `阅读3.0 书源` 找更多。

### 2️⃣ 上传书籍

**方式 A：网页上传** —— 书库页面 → 上传按钮

**方式 B：命令行上传**（适合批量）
```bash
gcloud compute scp ./我的书.epub reader-server:/tmp/ --zone us-west1-b
gcloud compute ssh reader-server --zone us-west1-b \
  --command "sudo mv /tmp/*.epub /books/"
```

### 3️⃣ 手机接入

| 设备 | 方法 |
|---|---|
| **Android** | 装 [Legado](https://github.com/gedoor/legado) → 书源管理 → 添加「阅读3.0 服务器版」→ 填地址和账号 |
| **iPhone** | Safari 打开地址 → 分享 → **添加到主屏幕**（像 App 一样用） |
| **浏览器** | 直接访问，功能最全 |

## 常见问题

<details>
<summary><b>会扣费吗？</b></summary>

不会。e2-micro + 30GB 标准盘完全在 Always Free 额度内。脚本已限制在免费区域（`us-west1`/`us-central1`/`us-east1`）。

**双保险**：到 `结算 → 预算和提醒` 设置 $1 预算提醒。
</details>

<details>
<summary><b>打不开网页？</b></summary>

首次部署要下载 Docker 镜像，等 2～3 分钟。查看进度：
```bash
gcloud compute ssh reader-server --zone us-west1-b \
  --command "sudo tail -f /var/log/reader-bootstrap.log"
```
</details>

<details>
<summary><b>怎么备份数据？</b></summary>

所有数据都在 `/data`：
```bash
gcloud compute ssh reader-server --zone us-west1-b
sudo systemctl stop reader
sudo tar czf /tmp/backup.tar.gz -C /data .
exit
gcloud compute scp reader-server:/tmp/backup.tar.gz ./ --zone us-west1-b
```
</details>

<details>
<summary><b>想省钱可以关机吗？</b></summary>

可以。关机后**不占用免费时长，磁盘仍免费保留**：
```bash
gcloud compute instances stop reader-server --zone us-west1-b
gcloud compute instances start reader-server --zone us-west1-b
```
</details>

<details>
<summary><b>能用 Netlify 吗？</b></summary>

**不能。** Netlify 是静态网页托管，无法运行需要常驻进程和数据库的服务器。详见主 README 开头的说明。
</details>
